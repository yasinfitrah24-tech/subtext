HOW IT WORKS

Five checkpoints

before your agent reads.

Every file in an untrusted repo passes through a gate before any AI agent is allowed to read it. Nothing from the repo is executed along the way.

Read-only, never run
02

03
Rules scan
8 patterns, under 10 ms
04
Granite judges
Flagged snippets only
05
Verdict
SAFE · REVIEW · BLOCK
