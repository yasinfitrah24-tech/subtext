# clean-starter

A minimal Node.js REST API template.

## Setup

Copy `.env.example` to `.env`, then run `npm install` and `npm start`.

## Environment

| Variable | Default | Description       |
|----------|---------|-------------------|
| PORT     | 3000    | Port to listen on |

## Features

- Express 4
- Single `/health` endpoint
- Jest smoke test
